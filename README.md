# Loan Management System

A distributed, end-to-end Loan Management System engineered with Spring Boot, Spring Cloud, Netflix Eureka, Spring Cloud Gateway, OpenFeign, and Spring Security with Role-Based Access Control (RBAC).

## 📦 Microservices Breakdown

| Service | Port | Role & Key Features |
| :--- | :--- | :--- |
| **`1-eureka-server`** | `8761` | **Service Registry**: Netflix Eureka discovery server for dynamic registration and routing. |
| **`gate-way-secure-role-based`** | `8080` | **API Gateway**: Single entry point handling request routing and JWT RBAC filters (`ROLE_user`, `ROLE_admin`). |
| **`identity-service`** | `9898` | **Identity & Access Management**: User registration, credential hashing with BCrypt, and JJWT token generation. |
| **`customer-service`** | `8000` | **Customer Management**: Profile creation, KYC verification lifecycle, and customer record management. |
| **`loan-service`** | `8210` | **Loan Core**: Loan schemes catalog, application submission, and multi-step approval evaluation engine. |
| **`Payment-Service`** | `8300` | **Payment Processing**: EMI collection, due balance recalculation via Feign proxy, and transaction history. |
| **`notification-service`** | `8500` | **Notification Dispatcher**: Automated email confirmations and status updates via Spring Mail / SMTP. |
| **`report-service`** | `8400` | **Report Aggregator**: Cross-service data consolidation (customer, loans, payments) using OpenFeign clients. |

## 🔄 Loan Workflow Lifecycle

1. **Onboarding & Authentication:** Users register and authenticate via Identity Service to obtain a JWT bearer token.
2. **KYC Verification:** Customer profile is submitted; Administrator verifies the customer's KYC status (`VERIFIED`).
3. **Loan Application:** The customer browses loan schemes and submits a loan application.
4. **Approval Evaluation:** Administrators evaluate the loan application based on credit eligibility and KYC validation.
5. **Repayment & EMI:** Once approved, EMI payments are submitted through the Payment Service, updating loan balances.
6. **Alerts & Reports:** Email receipts are dispatched via Notification Service, and consolidated statements are generated by the Report Service.

## 🛠️ Technology Stack

- **Framework:** Spring Boot 3.3.4, Spring Cloud (2023.0.3)
- **Security:** Spring Security, JSON Web Tokens (JJWT), Reactive Security
- **Discovery & Gateway:** Netflix Eureka Server & Client, Spring Cloud Gateway
- **Inter-Service Communication:** Spring Cloud OpenFeign
- **Persistence:** Spring Data JPA, Hibernate, Oracle JDBC Driver (`ojdbc11`)
- **Documentation & Testing:** SpringDoc OpenAPI (Swagger UI), JUnit 5, Mockito
- **Build Tool:** Apache Maven
